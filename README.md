# 🛒 Valorant Shop Tracker

Aplikacja mobilna pozwalająca na szybkie sprawdzenie aktualnych ofert w dziennym sklepie w grze Valorant. Projekt stworzony dla zabawy.

## 🚀 Technologie
- **Framework:** React Native / Expo
- **Budowanie i deployment:** EAS Build (Expo Application Services)
- **Kontrola wersji:** Git / GitHub

## 📱 Główne funkcje
- Przeglądanie aktualnych rotacji skinów w sklepie
- Optymalizacja pod systemy Android (APK) oraz iOS

## 🛠️ Jak uruchomić projekt lokalnie
1. Sklonuj repozytorium: `git clone https://github.com/K4mil-0/valorant-shop`
2. Zainstaluj zależności: `npm install`
3. Uruchom serwer deweloperski: `npx expo start`
