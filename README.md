# 🛒 Valorant Shop Tracker

Aplikacja mobilna do śledzenia dziennego sklepu w grze Valorant. Projekt stworzony w celach edukacyjnych oraz jako element portfolio w technologii React Native i Expo.

---

## 📱 Pobierz i przetestuj aplikację

Chcesz sprawdzić, jak aplikacja działa w praktyce? Pobierz gotową wersję instalacyjną na swój telefon z systemem Android:

- **[📥 Pobierz wersję APK na Androida](https://expo.dev/artifacts/eas/cvdPI-JwlFO0IzxhjWWmZoy0p4XX6P1d-IB1TEFfL_I.apk)**  
  *(Kliknij link, pobierz plik na telefon i zainstaluj aplikację)*

---

## 🚀 Technologie
- **Framework:** React Native / Expo
- **Build system:** EAS Build (Expo Application Services)
- **Kontrola wersji:** Git / GitHub

## ✨ Funkcje
- Podgląd rotacji skinów
- Wsparcie dla platform mobilnych

## 🛠️ Jak uruchomić projekt lokalnie
1. Sklonuj repozytorium: `git clone https://github.com/K4mil-0/valorant-shop`
2. Zainstaluj zależności: `npm install`
3. Uruchom serwer deweloperski: `npx expo start`
